# Cyclone Sensor Analytics and RAG-Based Technical Knowledge System

Two independent deliverables for a data science take-home assignment.

## Task 1 — Cyclone Sensor Analytics
Analysis of cyclone machine sensor data, including:
- Exploratory data analysis
- Shutdown and idle detection
- Operational-state clustering
- Contextual anomaly detection
- Short-horizon forecasting
- Operational insights and recommendations

## Task 2 — RAG-Based Technical Knowledge System
A Retrieval-Augmented Generation prototype for querying technical PDF documents, including:
- PDF ingestion and text extraction
- Document chunking and embeddings
- FAISS and BM25 hybrid retrieval
- Cross-encoder reranking
- LLM-based answers with citations
- FastAPI backend and Streamlit interface

## Project structure

- `Task1/` — Sensor analytics
- `Task2/` — RAG prototype
- `docs/` — Assignment and architecture documentation

Each task has its own Python environment and requirements file.
